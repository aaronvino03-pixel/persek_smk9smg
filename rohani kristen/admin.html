Masuk pengurus

Halaman ini untuk mengubah isi situs dan memeriksa kritik & saran. Gunakan akun yang diberikan admin.

Server masih memakai kode lama. Versi terbaru menyiapkan Spreadsheet sendiri, jadi tidak perlu menjalankan fungsi apa pun. Perbarui sekali saja:

  1. Buka apps-script/Code.gs di komputer → Ctrl+A → Ctrl+C.
  2. Di editor Apps Script: Ctrl+A → Delete → Ctrl+V → Ctrl+S.
  3. Deploy → Manage deployments → Edit → Version: New version → Deploy.
  4. Muat ulang halaman ini, lalu masuk lagi. Spreadsheet dibuat otomatis saat login pertama.

Jangan mengetik ulang kode atau menyalinnya dari chat — spasi bisa hilang. Salin langsung dari berkas di komputer.

Lupa sandi? Hubungi admin persekutuan. Jangan bagikan sandi ke siapa pun.

Server belum diatur

Halaman admin membutuhkan backend Google Apps Script. Ikuti langkah ini sekali saja:

  1. Buka script.google.com → New project.
  2. Tempel isi apps-script/Code.gs ke file Code.gs.
  3. Ganti username dan sandi pada ADMIN_AWAL, lalu jalankan fungsi siapkan.
  4. Deploy → New deployment → Web app. Pilih Execute as: Me dan Who has access: Anyone.
  5. Salin URL yang berakhiran /exec, lalu tempel di api.js:
const API_URL = "https://script.google.com/macros/s/.../exec";

Setelah itu unggah ulang api.js dan muat ulang halaman ini.

Periode kepengurusan

Isi pembina, pengurus, dan anggota. Periode yang ditandai aktif menjadi pilihan utama di halaman Pengurus dan Anggota.

Periode yang belum pernah disimpan tidak akan tampil di situs. Klik Simpan periode setelah mengisi.

Penting saat pertama kali dipakai: selama server masih kosong, situs menampilkan data bawaan dari data.js. Begitu periode pertama disimpan, situs hanya memakai data dari server. Isi dulu semua periode yang ingin tetap tampil (termasuk anggota) sebelum menyimpan.

Impor data bawaan situs

Menyalin seluruh periode (pembina, pengurus, anggota) dari data.js ke server. Paling berguna sekali saja, saat pertama memasang, supaya tidak perlu mengetik ulang.

Periode dengan nama yang sama di server akan ditimpa. Acara, renungan, dan galeri hanya diisi bila tabnya masih kosong, jadi perubahan yang sudah dibuat tidak hilang.
